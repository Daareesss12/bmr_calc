## Deskripsi 
### Cara Menggunakan di Tampilan Input
#### Langkah 1
Buka Aplikasi

#### Langkah 2
Akan muncul di Page input yang diperlukan. 
Klik tombol Male untuk Pria atau Female untuk Wanita

#### Langkah 3
- Geser Slider untuk Tinggi Badan
- Klik **+** untuk menambah Berat Badan dan  **-** untuk mengurangi Berat Badan yang diinput
- Klik **+** untuk menambah Umur dan  **-** untuk mengurangi Umur yang diinput

#### Langkah 4
Klik tombol **CALCULATE**

### Tampilan Result
 Menampilkan Page berisi Hasil perhitungan Basal Metabolic Rate (BMR) sesuai yang diinput/diisi di bagian Tampilan Input

#### Jika ingin mengulang hasil perhitungan yang berbeda :
Klik tombol **Re-Calculate**
